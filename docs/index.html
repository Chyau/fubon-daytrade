3. 頁面操作

📊 儀表板

• KPI：交易數／勝率／總淨損益／**期望值每筆**／獲利因子／平均R／最大回撤 • 累計損益曲線＋最近 12 筆交易（點日期進詳情）

⚡ 自動執行（核心頁面）

1. 標的欄會自動帶入建議（盤前清單→籌碼候選→掃描器推薦），可自行修改

2. 模式：dry＝只記錄不送單（預設零風險）／test＝富邦沙箱自動送單

3. 行情來源：富邦SDK（即時）／yfinance（延遲15-20分）

4. 「僅交易時段」預設開（平日 08:45–13:35）；關閉＝強制執行（收盤後重播當日走勢，供測試）

5. 啟動後頁面每 5 秒刷新：持倉監控（進價/當前停損/浮動損益）＋即時事件流

6. 流程自動執行：長黑K → 下一根開盤放空 → 每根新長黑K停損下移 → 13:20 強制買回 → 出場即止

7. ⚠ 重啟 app 後引擎停止，需重新啟動（狀態不持久）

📋 交易紀錄 ＋ 交易詳情

• 列表含停損軌跡（初始→最終、更新次數） • 詳情頁：進出場原因碼、事件流（TRIGGER/ENTRY/STOP_UPDATE/EXIT）、**進場特徵快照**（學習用 JSON）

📈 交易績效

• 完整指標＋**期望值拆解**：`E = 勝率×平均獲利 − 敗率×平均虧損` • 判讀：**E > 0 即正期望系統**。趨勢跟隨勝率偏低（35–50%）是本質，靠高盈虧比獲利 • 預設統計全部歷史；單次結果用 `?run_id=`（回測後自動帶入）

🧠 學習迴路（避免採同樣的坑）

• **坑點挖掘**：交易按維度（進場時段/實體%/星期/標的/出場原因/標籤…）分組，

「樣本≥4 且虧損率高出全體≥20個百分點且 avgR<0」→ 標記 ⛔ 坑

• **規則生命週期**：建立（未核准）→ 核准 → **引擎/回測自動擋下符合進場（E_RULE_BLOCK）** → 撤銷 • 進場端維度才可下規則：trigger_bucket／weekday／symbol／body_pct_band • 提醒：exit_reason/result_tag 維度是「結果歸因」，僅供複盤，不可下進場規則（事後偏誤）

🧲 籌碼選股

• 隔日沖候選：最新交易日**漲停 ∩ 分點買超≥門檻**（來源 tw-chips-daily 分點買超） • 漲停隔日表：來源 chengwaye（每日 17:05 更新）；統計「開盤+2.7% → 收盤+0.24%（勝率45%）」

＝ 開高走低常態，是隔日沖放空的統計依據

• 個股查詢：分點買超明細、外資/融券/大戶（欄位語義以官網為準，標「推測」者勿直接作為依據）

🧾 下單紀錄

• 每筆真實送單（成功/失敗、測試/正式、委託號）皆入庫；來源：CLI `--send` 或自動執行 test 模式

⏱ 回測（三種資料源）

資料源內容適用
**富邦 SDK（預設）**測試環境真實模擬行情，**最新交易日 54 根完整 5 分K**（09:00–13:30）；歷史日期查詢不支援引擎驗證、當日複盤
yfinance台股 5 分K（60 天內），**資料可能稀疏**、UTC 已轉台北時區多日回測
合成資料固定種子亂數（標的代碼僅是標籤，各標的結果相同）管線驗證
• CLI 等效：`python backtest.py --fubon 2330`／`--yf 2426.TW --period 60d`／`--csv 檔案`／`--demo` • 誠實原則：**評估策略真實績效，以富邦當日資料＋累積多日為主，勿用合成數據下結論**

📖 手冊／API

• 本手冊；JSON API：`/api/stats`、`/api/trades?limit=N`（供日後 Telegram/AI）

5. 下單 CLI（fubon_orders.py）

python fubon_orders.py --dry  --symbol 2344 --side sell --qty 1000 --short --price 60   # 只輸出參數
set PLACE_ORDER=true
python fubon_orders.py --send --symbol 2344 --side sell --qty 1000 --short --price 60 --yes  # 真實下單
python fubon_orders.py --status      # 今日委託（status=30＝已刪單）
python fubon_orders.py --cancel ORDER_NO

四道安全閘：--send → PLACE_ORDER=true → 環境確認（沙箱 --yes／正式 --yes＋輸入代號）→ 登入與漲跌停驗證。

切換正式盤：測試環境先通 10 筆 → FUBON_USE_TEST=0＋填 FUBON_LIVE_* → 再執行。

7. 常見問題

• **勝率不高？** 趨勢跟隨本質（等確認才進場）。看期望值：E>0 即可長期獲利。 • **回測結果各標的都一樣？** 你用了「合成資料」——換成富邦 SDK／yfinance。 • **富邦回測只有一天？** 測試環境歷史日期查詢不支援（回傳最新日），多日請用 yfinance/CSV。 • **引擎收盤後沒反應？** 「僅交易時段」開啟中；測試可取消勾選強制執行。 • **yfinance 時間怪怪的？** 已統一轉台北時區；若仍異常請更新 yfinance。

7.1 進階功能

多空分類清單橋接（權證小哥 tw_stock.db）

系統會自動讀取 D:\權證小哥-當沖飆股神手\twdata\tw_stock.db 的 longshort_signal 表，

取最新基準日的做空＋偏空清單（做空優先、bias_score 越空越前）：

• **⚡自動執行**：`/live` 頁「啟動」表單的標的欄自動預填多空清單（24 檔）；

引擎 API 的建議標的（suggest_symbols）也以多空清單為最高優先，

無資料時後備：盤前觀察清單 → 籌碼候選 → 掃描器推薦。

• **⏱ 線上回測**：`/backtest` 頁表單自動預填多空清單，可自行增刪後執行。 • **路徑自訂**：設定環境變數 `LONGSHORT_DB` 指向其他資料庫；DB 不存在時靜默後備，不影響其他功能。 • 手動查詢：`python live.py`（列印基準日＋24 檔標籤明細）；`start_web*.bat` 啟動時也會先顯示

此清單（python live.py --brief），之後才啟動伺服器。

長黑K參數網格校準

python backtest.py --fubon 2330 --sweep     # body_mult(1.0~2.0) × min_body_pct(0.3~1.0) 共 25 組

輸出各組合的筆數／勝率／淨損益／獲利因子／平均R（依淨損益排序）。⚠ 樣本內最佳化有過擬合風險，需跨期間／標的驗證。

從坑點一鍵建規則（證據鏈）

python journal.py pits --min-n 4 --save     # 挖掘結果先入庫
python journal.py rules --from-pit 1        # 從坑點 #1 建規則，自動帶證據備註

僅接受進場端維度（trigger_bucket／weekday／symbol／body_pct_band）；結果歸因維度（exit_reason／result_tag）會被拒絕（事後偏誤防護）。建立後仍需人工核准。

Telegram 通知（.env：TELEGRAM_BOT_TOKEN／TELEGRAM_CHAT_ID）

填入後自動通知：⚡自動執行的進場/出場/擋單事件、真實下單結果（CLI 與引擎）、回測完成摘要。未填＝靜默關閉。

條件單（Smart Condition）

python fubon_condition.py --list                                   # 查有效條件單
python fubon_condition.py --stop 2330 --qty 1000 --trigger 2380.0  # 停損買回（放空保護）
python fubon_condition.py --entry 2330 --qty 1000 --trigger 2400 --side sell   # 進場觸發＋13:20自動回補
python fubon_condition.py --cancel GUID                            # 取消
• ⚠ 當日效期條件單限**營業日 08:30–16:32** 送出；預下單需用多條件單／停損停利單 • ⚠ 需先於券商完成「條件單使用同意書」簽署 • 引擎可選保護：設環境變數 `LIVE_AUTO_CONDITION=1` → test 模式進場時自動下停損條件單（雙保險）

8. 風險聲明

本系統為輔助工具，不構成投資建議。測試環境行情為模擬資料；

實單前請於測試沙箱完成至少 10 筆演練，並以券商官方回報為最終依據。
